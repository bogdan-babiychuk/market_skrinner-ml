# MarketScreener ML

Модель для обнаружения локальных разворотов на минутных рыночных данных. Будет определять разворот вверх, разворот вниз или отсутствие разворота и передавать результат вместе с вероятностями в слой принятия решений MarketScreener.

Подробное описание — в [Model Card](model_card.md).
